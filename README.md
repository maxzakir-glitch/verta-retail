# VERTA — продуктовый ритейл

Одна адаптивная страница без роутинга, табов, отдельных страниц категорий и вымышленных товарных характеристик. Разделы всегда раскрыты; навигация только прокручивает страницу. Один popup используется всеми кнопками «Узнать цену».

## Файлы
- `index.html` — содержимое всех разделов.
- `style.css` — фирменный Gilroy, тёмная шапка/первый экран/портфолио, красные кнопки, серый градиент блоков производства; сетка на основе исходного сайта VERTA.
- `app.js` — ручные слайдеры, одна форма запроса, валидация, ненавязчивая анимация с reduced motion.
- `catalog.js` — пополняемые каталоги и проекты.
- `assets.zip` — локальные шрифты и оптимизированные фотографии; распакуйте в папку сайта. DOCX, таблица с контактами и другие внутренние материалы не публикуются.

## Открыть и редактировать
Распакуйте `assets.zip` рядом с `index.html` и откройте `index.html` двойным щелчком. Сборка и установка пакетов не нужны. Для локального сервера: `python -m http.server 8000`.

## Каталоги
В `catalog.js` массивы изначально пустые: утверждённых изделий, их размеров и материалов в ТЗ нет. Добавляйте реальные объекты с полями `name`, `dimensions`, `material`, `image`. Они выводятся непосредственно в разделе на этой же странице. Цены не выводятся. Общая кнопка направления остаётся доступной и до заполнения каталога.

## Проекты
Добавляйте фотографии в `projects`. `supermarket: true` включает фото в большой слайдер ритейла. `categories: ['bakery']` включает его в ручной слайдер хлебного раздела. Первоначально использованы два подтверждённых фото «Глобуса» с исходного сайта; это не автоматическая синхронизация полного WordPress-портфолио.

## Формы
Пока `formEndpoint` пуст, данные никуда автоматически не отправляются. Пользователь может открыть письмо с заявкой. Для рабочей отправки подключите свой сервер/CRM. Не публикуйте секреты в JavaScript. GitHub Pages не исполняет серверный PHP.

## Публикация
Workflow распаковывает локальные материалы и публикует GitHub Pages при изменении main. Если Pages ещё не включён, откройте Settings → Pages → Source → GitHub Actions.

## Учтённые комментарии Word
- Сохранён SEO-заголовок «Производим торговое оборудование для современного ритейла».
- «Магазин под ключ» исключён из перечня отделов: объединяющий смысл раскрыт блоком «От идеи до открытия магазина».
- Указания ТЗ об отдельных разделах адаптированы по последней правке заказчика: все разделы на одной странице.
- Не добавлены сторонние рекламные обещания, вымышленные модели, цены или схемы shop-in-shop. Фото modi, Яндекс Фабрики, ЭкоНивы и Tefal — референсы из документа, а не работы VERTA.

## Что ещё нужно для промышленной версии
Утвердить реальный товарный каталог; выбрать фотографии проектов по отделам; разработать типовые shop-in-shop; подключить форму и полное WordPress-портфолио; встроить новую страницу в существующую тему WordPress. Этот репозиторий — автономный прототип для согласования, а не изменение сайта verta62.ru.
